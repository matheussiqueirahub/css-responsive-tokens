# Exercício: Variáveis CSS Responsivas

Este repositório contém uma página de estudo para praticar a criação de variáveis CSS usadas em tipografia e espaçamentos responsivos.

## Visual do Exercício

![Exemplo de layout responsivo](assets/exemplo-layout.svg)

## Como usar

- Abra `index.html` no navegador e redimensione a janela para visualizar as mudanças de fonte e espaçamento nos breakpoints de `768px` e `1024px`.
- Ajuste os valores declarados em `:root` e nas media queries para experimentar diferentes variações.
- Inclua novas variáveis se quiser controlar outros aspectos, como cores ou tamanhos de borda, mantendo o layout consistente.

## O que praticar

- Centralizar a definição de tokens de design com variáveis CSS.
- Reaproveitar variáveis em tipografia e espaçamentos.
- Atualizar o layout usando media queries para diferentes tamanhos de tela.
